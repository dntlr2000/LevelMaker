# Rogue Dungeon Lab - Baking Tools

영속 Mesh·Prefab Bake와 Baked Stage `.unitypackage` 배포 계획을 제공하는 Editor-only package입니다. Runtime Core를 요구하며 Lab Sample은 요구하지 않습니다.

UPM 소비 프로젝트에서는 Core가 별도 package이므로 `Baked Stage 묶음` modular 내보내기를 사용하세요. Core 포함 standalone `.unitypackage`는 개발 원본의 기존 R9 배포 메뉴에서 생성합니다.
