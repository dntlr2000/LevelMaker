# Rogue Dungeon Lab - Lab Sample

실험용 인게임 HUD, 자유 카메라, 클릭 상호작용과 임시 플레이어를 제공하는 선택 package입니다. Runtime Core와 Input System을 요구합니다. 0.14.0에는 Editor-only FPS 아레나 제작 창(지형·엄폐·적·특수 기믹·아이템·프리팹 6개 탭)도 포함됩니다. `Tools > Rogue Dungeon Lab > FPS 아레나 제작`에서 시작합니다.

0.17.0: 직접 설계 창에서 새 맵/현재 맵의 셀 크기·층간 높이·가로·세로·층 수를 편집합니다. 확대는 새 영역에 바닥만 추가하고 범위 밖 데이터가 있는 축소는 사유를 표시하며 보류합니다. 벽 높이·두께를 개별/현재 층/전체 층에 적용하고 내부·외곽 배치 기본값을 별도로 저장합니다. 기존 치수·ID를 자동 변경/삭제하지 않으며 각 적용은 Undo를 지원합니다. 자산 저장과 장면 적용은 별도로 실행합니다.

0.16.0: 새 수동 스테이지는 외곽벽 없이 시작합니다. `벽 자동 배치 (전체 층)`은 전체 층의 외곽과 내부 구멍에서 빈 경계만 채우며 계단은 제외합니다. 네 방향 경계에서 벽/문/선택/삭제를 사용하고, 삭제한 외곽은 저장·로드로 복구되지 않습니다. v1 자산은 `편집형 벽으로 변환 (Undo 가능)` 후 편집합니다. 기존 외곽 규격과 절차 시드/해시는 유지합니다.

0.15.0: `Tools > Rogue Dungeon Lab > 스테이지 직접 설계`에서 빈 판을 만들거나 생성 결과를 복사합니다. 층별 격자에서 바닥·벽·문·계단·시작 스폰·구조물·적·기믹·아이템을 편집하고 저장합니다. 선택 도구로 콘텐츠를 드래그하고 Ctrl+Z/Redo로 되돌립니다. 검사 후 장면에 적용하고 테스트 플레이어를 연결한 뒤 Play로 확인하세요. 전체 연결성 부족은 경고만 표시하고 좌표·계단·겹침·프리팹 연결의 필수 오류만 적용을 차단합니다.

다른 프로젝트의 프리팹은 `프로젝트 프리팹 등록·교체`에서 같은 콘텐츠 키로 등록하세요. 카탈로그를 복제하여 Generator의 `호스트 카탈로그 교체`에 연결하면 스테이지 자산을 수정하지 않고 교체됩니다. `IFpsArenaContentInitializer`는 기존 게임 시스템 연결용 hook입니다.

제품 장면에서 Lab 컴포넌트를 배치하지 않으면 빌더 HUD는 표시되지 않습니다. Core-only 제품에는 이 package를 설치하지 않아도 됩니다.
